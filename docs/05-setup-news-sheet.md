# News 시트 셋업 가이드

> **대상**: 시트를 처음 만드는 관리자 (보통 교수님 또는 시스템 담당자)
> **소요 시간**: 약 10분
> **선행 조건**: 기존 워크북에 멤버/Publications/Partners 탭이 있는 상태

이 가이드는 같은 워크북에 News 관련 세 개 탭(**Notice**, **Media Coverage**, **Co-Lab**)을 추가하는 절차입니다.

각 탭의 데이터는 자동으로 홈페이지의 `/news` 페이지에 표시됩니다.

---

## 1. `Notice` 탭 만들기 (공지사항)

### 1-1. 탭 생성
1. 워크북 하단 `+` 버튼 클릭
2. 새 시트 이름을 **`Notice`** 로 변경

### 1-2. 헤더 입력
A1부터 E1에 다음을 입력:

| 셀 | 헤더 |
|---|---|
| A1 | 제목 |
| B1 | 날짜 |
| C1 | 본문 |
| D1 | 첨부 링크 |
| E1 | 대표이미지 |

### 1-3. B열 (날짜) 형식 통일
- B2 이하 셀들 선택 → **서식 → 숫자 → 날짜** → `2026-05-26` 형식 추천
- 또는 자유 입력 (예: `2026-05-26`, `2026.05.26` 둘 다 OK)

### 1-4. 입력 방법

| 셀 | 내용 | 예시 |
|---|---|---|
| A (제목) | 공지 제목 | "2026년 봄학기 세미나 안내" |
| B (날짜) | 게시일 | `2026-05-26` |
| C (본문) | 1~3 문장의 간단 본문 | "5월 30일 오후 2시, GIST 본관 1층에서 진행됩니다." |
| D (첨부 링크) | 외부 링크 (선택) | Google Drive 첨부 / 외부 URL |
| E (대표이미지) | 카드 이미지 URL (선택, Google Drive 공유 링크 권장) | `https://drive.google.com/file/d/.../view?usp=sharing` |

> 💡 **D열을 비워두면** 카드는 본문만 표시됩니다. 링크가 있으면 카드 클릭 시 새 탭에서 열림.
> 💡 **E열을 비워두면** 카드에 자동 placeholder(그라데이션 + 카테고리 아이콘)가 표시됩니다.

---

## 2. `Media Coverage` 탭 만들기 (언론 보도)

### 2-1. 탭 생성
새 시트 이름을 **`Media Coverage`** 로 변경 (공백 그대로)

### 2-2. 헤더 입력
A1부터 E1에 다음을 입력:

| 셀 | 헤더 |
|---|---|
| A1 | 제목 |
| B1 | 매체명 |
| C1 | 날짜 |
| D1 | 기사 링크 |
| E1 | 대표이미지 |

### 2-3. 입력 방법

| 셀 | 내용 | 예시 |
|---|---|---|
| A (제목) | 기사 제목 | "AI-ACE 연구단, 뇌질환 조기진단 AI 개발" |
| B (매체명) | 신문/방송사 이름 | "동아일보" / "Nature News" |
| C (날짜) | 보도일 | `2026-05-20` |
| D (기사 링크) | 기사 URL | `https://www.donga.com/news/...` |
| E (대표이미지) | 기사 썸네일/대표 이미지 (선택, Google Drive 권장) | Drive 공유 링크 |

> 💡 카드 전체가 외부 기사 링크로 동작 — 클릭 시 새 탭에서 기사가 열립니다.
> 💡 E열 비워두면 카테고리별 placeholder 자동 표시.

---

## 3. `Co-Lab` 탭 만들기 (연구단 행사 사진)

### 3-1. 탭 생성
새 시트 이름을 **`Co-Lab`** 으로 변경

### 3-2. 헤더 입력
A1부터 C1에 다음을 입력:

| 셀 | 헤더 |
|---|---|
| A1 | 제목 |
| B1 | 날짜 |
| C1 | 사진 링크 |

### 3-3. 입력 방법

| 셀 | 내용 | 예시 |
|---|---|---|
| A (제목) | 행사명 또는 사진 설명 | "2026 봄 워크샵" |
| B (날짜) | 행사일 | `2026-04-15` |
| C (사진 링크) | Google Drive 공유 링크 | `https://drive.google.com/file/d/.../view?usp=sharing` |

### 3-4. 사진 업로드 (Co-Lab 핵심)

1. 행사 사진을 Google Drive에 업로드 (PNG/JPG/WebP)
2. 우클릭 → "공유" → **"링크가 있는 모든 사용자"** 권한 설정 ← 필수!
3. "링크 복사" → C열에 붙여넣기

> 💡 권한이 "본인만"이면 다운로드 실패합니다. (Partners 로고와 동일한 패턴)

### 3-5. 권장 비율
- 4:3 또는 16:9 가 잘 어울립니다
- 너무 큰 파일(20MB 이상)은 압축 후 업로드 권장 (Drive virus scan 페이지 우회)

---

## 4. 데이터 검증 / 헤더 고정 (선택)

각 탭에서:
- 1행 헤더 굵게 + 배경색 설정
- 메뉴 **보기 → 고정 → 1행**

---

## 5. 자가 점검 체크리스트

- [ ] `Notice`, `Media Coverage`, `Co-Lab` 세 탭이 만들어졌다
- [ ] `Notice` 탭: A1=제목, B1=날짜, C1=본문, D1=첨부 링크, E1=대표이미지
- [ ] `Media Coverage` 탭: A1=제목, B1=매체명, C1=날짜, D1=기사 링크, E1=대표이미지
- [ ] `Co-Lab` 탭: A1=제목, B1=날짜, C1=사진 링크
- [ ] 각 탭에 테스트 데이터 1줄씩 입력
- [ ] GitHub Actions → "Sync News" 수동 실행 → 1~2분 후 ✅ 확인

---

## 6. 동작 흐름

```
[행정 담당자]
   ↓
시트 3개 탭 입력
   ↓
매일 KST 00:45 (또는 수동) sync-news 워크플로우 실행
   ↓
news.json 갱신 + Co-Lab 사진 다운로드
   ↓
GitHub Pages 자동 재배포
   ↓
홈페이지 /news 페이지에 반영
```

---

## 7. 행정 담당자에게 전달

이 가이드 완료 후:
- 행정 담당자는 **시트 3개 탭에 입력**만 하면 됩니다
- 각 탭마다 다른 컬럼 형태이지만 입력 패턴은 단순 (제목/날짜/본문 또는 링크)
- 채용공고는 별도 **Opportunities 탭**에 입력 (`docs/06-setup-opportunities-sheet.md` 참고)
