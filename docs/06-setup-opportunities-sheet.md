# Opportunities 시트 셋업 가이드

> **대상**: 시트 관리자
> **소요 시간**: 약 5분
> **선행 조건**: 기존 워크북 사용

이 탭은 **채용공고/펠로우십/인턴** 등 모집 공고를 관리하는 곳입니다. 입력된 데이터는:
- `/opportunities` 페이지에 전용 카드로 표시
- `/news` 페이지의 **Notice 카테고리**에도 자동으로 같이 노출 (마감일 미도래 활성 공고만)
- 마감일이 지나면 자동으로 비활성화

---

## 1. `Opportunities` 탭 만들기

### 1-1. 탭 생성
1. 워크북 하단 `+` 버튼 클릭
2. 새 시트 이름을 **`Opportunities`** 로 변경

### 1-2. 헤더 입력

A1부터 F1에 다음을 입력:

| 셀 | 헤더 |
|---|---|
| A1 | 제목 |
| B1 | 유형 |
| C1 | 마감일 |
| D1 | 본문 |
| E1 | 지원방법 |
| F1 | 활성 |

### 1-3. 데이터 검증 — 유형 (B열)

1. B2:B1000 선택
2. 메뉴 **데이터 → 데이터 확인**
3. 기준: **드롭다운**, 항목 직접 입력:
   - `fellowship` — 펠로우십
   - `position` — 정규직/포닥
   - `intern` — 인턴
   - `other` — 기타
4. 잘못된 데이터일 경우: **거부**
5. 저장

### 1-4. 날짜 형식 — 마감일 (C열)

C2 이하 셀들 선택 → **서식 → 숫자 → 날짜** → `2026-12-31` 형식
- 자동 만료 처리를 위해 **날짜 형식이 중요**합니다
- 빈 값이면 마감일 없는 상시 공고로 처리됨

### 1-5. 활성 (F열) — 자동 처리

- F열은 **sync 스크립트가 자동으로 채움** (행정이 직접 입력 안 함)
- 마감일 기준 자동 처리:
  - **마감일 > 오늘** → `TRUE` (활성, 페이지에 표시됨)
  - **마감일 ≤ 오늘** → `FALSE` (비활성, 페이지에서 숨김)
  - **마감일 비어있음** → `TRUE` (상시 공고)
- 수동 비활성화: 행정이 F열에 `FALSE` 입력 → 즉시 숨김

### 1-6. 입력 방법

| 셀 | 내용 | 예시 |
|---|---|---|
| A (제목) | 공고 제목 | "InnoCORE Fellowship 2026 모집" |
| B (유형) | 드롭다운 | `fellowship` |
| C (마감일) | YYYY-MM-DD | `2026-12-31` (없으면 빈칸 = 상시) |
| D (본문) | 공고 본문 (1~5 문장) | "AI-ACE 연구단의 InnoCORE Fellowship 2026 모집 안내. 50명 선발 예정." |
| E (지원방법) | 이메일 또는 외부 폼 URL | `innocore_apply@gist.ac.kr` 또는 Google Form 링크 |
| F (활성) | 자동 (또는 수동 `FALSE` 입력) | (비워둠) |

## 2. 자가 점검 체크리스트

- [ ] `Opportunities` 탭이 워크북에 존재
- [ ] A1~F1 헤더 정확히 입력
- [ ] B열 드롭다운에서 `fellowship`/`position`/`intern`/`other` 선택 가능
- [ ] C열 날짜 형식 OK (`2026-12-31`)
- [ ] 테스트 행 1개 입력 후 GitHub Actions → "Sync Opportunities" 수동 실행 → ✅

---

## 3. 동작 흐름

```
[행정 담당자]
   ↓
Opportunities 탭에 채용공고 입력 (마감일 포함)
   ↓
매일 KST 01:00 또는 수동 트리거
   ↓
sync-opportunities.mjs 실행
   ├─ 마감일 기준 활성/비활성 자동 처리
   ├─ opportunities.json 갱신
   └─ Notice 페이지에 자동 노출됨 (활성 공고만)
   ↓
사용자가 사이트에서 확인
   ├─ /opportunities 페이지 = 전용 페이지 (상세 정보 카드)
   └─ /news?tab=notice 페이지 = 일반 공지 + 활성 채용공고가 함께 보임
       └─ 채용공고 카드 클릭 → /opportunities 페이지로 이동
```

## 4. 자주 묻는 질문

**Q. 마감일이 지난 공고는 자동으로 삭제되나요?**
A. 삭제가 아닌 **비활성화**입니다. 시트에는 그대로 남아있지만 페이지에서 보이지 않습니다. 같은 공고를 다시 활용하려면 마감일만 수정하면 됩니다.

**Q. F열(활성)을 직접 `TRUE`로 바꾸면 마감일 무시되나요?**
A. 다음 sync 시점에 다시 마감일 기준으로 재계산됩니다. 마감일이 지난 공고를 임시로 보이게 하려면 마감일을 미래로 수정하세요.

**Q. 마감일 없이 상시 모집은 어떻게?**
A. C열(마감일)을 비워두면 됩니다. F열은 자동으로 `TRUE`가 되어 항상 활성.

**Q. 지원방법을 이메일과 폼 둘 다 받고 싶어요.**
A. E열에 둘 다 입력하시면 됩니다. 예: `innocore_apply@gist.ac.kr (or [Google Form](URL))`

**Q. 마감 임박 공고를 강조 표시할 수 있나요?**
A. 현재는 활성/비활성만 처리합니다. 마감 임박 표시가 필요하면 향후 확장 가능.

---

## 5. Notice 페이지와의 연계 동작

행정이 Opportunities 탭에 새 공고를 입력하면:

1. **/opportunities 페이지** — 정식 카드로 상세 정보 표시 (제목, 본문, 마감일, 지원방법)
2. **/news?tab=notice 페이지** — 일반 공지 카드들과 함께 "[채용공고]" 라벨이 붙은 카드로 자동 표시
3. Notice 페이지의 채용공고 카드를 **클릭하면 → /opportunities 페이지로 이동**

행정은 **Opportunities 탭에만 입력**하면 됩니다 (Notice 탭에 따로 안 적어도 됨).
