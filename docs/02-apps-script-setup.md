# Apps Script 설치 가이드

> **대상**: 시트에 자동 채움 스크립트를 등록할 관리자 (보통 교수님)
> **소요 시간**: 약 10분
> **선행 조건**: `docs/01-setup-publications-sheet.md` 완료 (시트 탭 생성됨)

이 작업은 **한 번만** 하면 됩니다. 이후 행정 담당자는 시트만 사용합니다.

---

## 1. Apps Script 편집기 열기

1. Publications 시트를 엽니다
2. 상단 메뉴 **확장 프로그램 → Apps Script** 클릭
3. 새 탭에서 Apps Script 편집기가 열립니다

---

## 2. 스크립트 코드 붙여넣기

1. 편집기 좌측 **파일 목록**에 `Code.gs` (또는 `코드.gs`)가 보입니다
2. 편집기 가운데 영역의 **기존 코드 전체를 삭제** 합니다
3. `/Users/mskim/Documents/2026-ai-innocore_webpage/scripts/apps-script/publications.gs` 파일을 엽니다
4. **그 파일의 전체 내용을 복사**해서 편집기에 붙여넣습니다
5. 상단 **디스크 아이콘(💾)** 또는 `Ctrl+S` / `Cmd+S` 로 저장

> 💡 저장 시 "프로젝트 제목" 입력 창이 뜨면 **`AI-ACE Publications`** 정도로 입력

---

## 3. 트리거(Trigger) 등록 — 자동 실행 설정

DOI 입력 시 자동으로 메타데이터를 가져오려면 **설치형 트리거**가 필요합니다.

> ⚠️ Apps Script의 단순 `onEdit` 함수는 외부 API 호출 권한이 없어서 Crossref를 부를 수 없습니다.
> 반드시 아래 절차로 **설치형 트리거**를 만들어야 합니다.

### 3-1. 트리거 페이지 열기

1. Apps Script 편집기 좌측 사이드바의 **⏰ 시계 아이콘** ("트리거") 클릭
2. 우측 하단 **+ 트리거 추가** 버튼 클릭

### 3-2. 트리거 설정값

| 항목 | 값 |
|---|---|
| 실행할 함수 선택 | **`onEditTrigger`** |
| 실행할 배포 선택 | `Head` |
| 이벤트 소스 선택 | **`스프레드시트에서`** |
| 이벤트 유형 선택 | **`수정 시`** |
| 실패 알림 설정 | `매일 알림` (권장) |

**저장** 클릭

### 3-3. 권한 승인

저장하면 **권한 요청 팝업**이 뜹니다:

1. **계정 선택** — 본인 Google 계정 선택
2. "Google에서 확인하지 않은 앱" 경고 화면이 나오면:
   - 좌측 하단 **"고급"** 클릭
   - **"AI-ACE Publications(으)로 이동(안전하지 않음)"** 클릭
   - (본인이 직접 만든 스크립트이므로 안전합니다)
3. 권한 목록 확인:
   - ✅ 스프레드시트 보고 수정
   - ✅ 외부 서비스에 연결 (Crossref API 호출용)
   - ✅ UI 메뉴 표시
4. **허용** 클릭

---

## 4. 메뉴 등록 확인

1. Apps Script 편집기 탭을 닫지 말고, **Google Sheet 탭으로 돌아갑니다**
2. **시트를 새로고침 (F5 또는 Cmd+R)** 합니다
3. 상단 메뉴에 **"📚 Publications"** 가 보이는지 확인
   - 일반적으로 "도움말" 메뉴 오른쪽에 추가됩니다
   - 안 보이면 잠시 기다린 후 다시 새로고침

---

## 5. 동작 테스트

### 5-1. 자동 채움 테스트

1. **Publications** 탭으로 이동
2. A2 셀에 다음 DOI 붙여넣기:
   ```
   10.1038/nature12373
   ```
3. Enter 키
4. **1~3초 후** G2(제목), H2(저자), I2(저널), J2(연도) 셀이 자동으로 채워지는지 확인
5. K2 셀에 **`OK`**, L2 셀에 **타임스탬프**가 표시되면 성공 ✅

### 5-2. 메뉴 동작 테스트

1. 상단 메뉴 **📚 Publications → ❓ 사용법** 클릭
2. 사용법 안내 창이 뜨면 성공 ✅

### 5-3. 일괄 새로고침 테스트

1. 상단 메뉴 **📚 Publications → 🔄 전체 새로고침** 클릭
2. 확인 창에서 OK
3. 완료 알림이 뜨면 성공 ✅

## 6. 트러블슈팅

### "메뉴가 안 보입니다"
- 시트를 한 번 새로고침해야 합니다 (`Cmd+R` / `F5`)
- Apps Script 편집기에서 `onOpen` 함수를 수동 실행 후 다시 새로고침

### "DOI를 넣어도 자동으로 안 채워집니다"
- 트리거가 등록되지 않았을 가능성 — 3장 다시 확인
- Apps Script 편집기 → 좌측 **실행** 아이콘 → 최근 실행 로그 확인
- 일반적인 원인:
  - 트리거 함수명을 `onEdit`로 잘못 선택 → **`onEditTrigger`** 가 맞음
  - 권한 승인 미완료

### "권한 승인이 다시 떠요"
- 정상입니다. Apps Script가 새로운 권한을 필요로 할 때마다 한 번씩 다시 요청합니다.

### "K열에 'Error'가 표시됩니다"
- 일시적 네트워크 오류일 수 있습니다
- 해당 행을 선택한 후 메뉴 → "📥 선택한 행 새로고침" 재시도
- 여러 번 실패하면 DOI가 정말 Crossref에 등록되지 않은 것 — 행정이 G~J를 수동 입력하고 K를 `manual` 로 변경

### "Crossref가 느려요 / 호출 한도가 걱정됩니다"
- Crossref는 polite pool 회원에게 50req/s를 보장합니다
- 우리 스크립트는 `mailto` 헤더를 포함하여 polite pool에 자동 등록됨
- 하루 수천 건 처리 가능 — 우리 연구단 규모에서는 한도 도달할 일 없음
