# 📚 Publications 관리 매뉴얼 (행정 담당자용)

연구단 홈페이지의 논문/특허 목록을 시트에서 관리합니다. 코드는 건드리지 않습니다 — 시트에만 입력하시면 매일 밤 자동으로 홈페이지에 반영됩니다.

---

## 한 줄 요약

> **교수님께 받은 DOI를 시트에 붙여넣으면, 제목·저자·저널이 자동으로 채워지고, 다음날 홈페이지에 올라갑니다.**

---

## 시트 열기

🔗 [Publications 시트 바로가기](https://docs.google.com/spreadsheets/d/1JBb_azDOmzVl3hCfJqqAWh1sGMHCB0tGey4k_OX7agY/edit)

시트를 열면 하단에 여러 탭이 있습니다:

- **`Members`** — 멤버 관리 (기존)
- **`Publications`** — 논문 관리 ← **이 매뉴얼의 대상**
- **`Patents`** — 특허 관리 ← **이 매뉴얼의 대상**

---

## 1. 새 논문 추가하기

### 1-1. 교수님께 DOI를 받습니다

이메일 예시:
> "안녕하세요, 이번에 Nature에 출간된 논문 DOI 공유드립니다: `10.1038/s41586-024-12345-6`"

### 1-2. `Publications` 탭으로 이동

### 1-3. 빈 첫 번째 행을 찾아서 입력

| 셀 | 입력할 내용 | 예시 |
|---|---|---|
| **A열 (DOI)** | DOI를 그대로 붙여넣기 | `10.1038/s41586-024-12345-6` |
| **B열 (제출 PI)** | 드롭다운에서 해당 PI 선택 | `Mansu Kim` |
| **C열 (분과)** | 드롭다운에서 분과 선택 (모르면 비워둠) | `Collective Intelligence` |
| **D열 (유형)** | 드롭다운에서 `publication` 선택 | `publication` |
| **E열 (Featured)** | 강조 표시할 논문이면 ✅ 체크 (보통 비워둠) | ☐ |
| **F열 (비고)** | 특이사항 (선택) | "표지논문" |

### 1-4. 자동 채움 확인 (1~3초)

DOI를 입력하고 Enter를 누르면 **1~3초 내에** 다음 컬럼이 자동으로 채워집니다:

- G열: 제목
- H열: 저자
- I열: 저널
- J열: 연도
- K열: 상태 → **`OK`** 가 표시되면 성공 ✅
- L열: 마지막 동기화 시각

### 1-5. 결과 확인

K열의 상태에 따라 다음 단계가 다릅니다:

| K열 상태 | 의미 | 조치 |
|---|---|---|
| **`OK`** ✅ | 정상적으로 가져왔습니다 | 끝! 다음 행으로 |
| `DOI 없음` ⚠️ | Crossref에서 못 찾음 | → [2장 참조](#2-doi가-안-가져와질-때) |
| `Error` ❌ | 일시적 오류 | 메뉴 → "📥 선택한 행 새로고침" 재시도 |
| (비어있음) | 자동 채움이 아직 안 일어남 | 잠시 기다리거나 [3장 참조](#3-자동-채움이-안-될-때) |

## 2. DOI가 안 가져와질 때

가끔 Crossref에 등록되지 않은 DOI가 있습니다 (특히 국내 학회지, 일부 출판사). 이 경우:

### 방법 A: DOI 다시 확인
교수님께 받은 DOI가 오타가 아닌지 확인 → 올바른 DOI로 수정

### 방법 B: 수동 입력
1. **G열(제목), H열(저자), I열(저널), J열(연도)** 에 직접 입력합니다
   - 저자는 콤마로 구분: `Kim, S., Lee, J., Park, H.`
2. **K열(상태)** 을 **`manual`** 로 변경합니다 (소문자 그대로)
   - 이렇게 하면 다음 자동 새로고침 때 덮어쓰지 않습니다 🔒

> 💡 **저자 형식 팁**: Crossref가 만들어주는 형식과 똑같이 `Family, F.` (성, 이름이니셜) 로 써주시면 일관성이 좋습니다.

## 3. 자동 채움이 안 될 때

**상황**: DOI를 입력했는데 1~2분이 지나도 G~J 컬럼이 비어있음

### 해결 순서

1. **메뉴 사용**: 상단의 **`📚 Publications`** 메뉴 → **`📥 선택한 행 새로고침`** 클릭
2. 그래도 안 되면 → 해당 행 전체를 선택 후 같은 메뉴 다시 실행
3. 여러 행을 한꺼번에 채우려면: 상단 메뉴 → **`🔄 전체 새로고침`**

### 📚 Publications 메뉴가 안 보이는 경우

- 시트를 새로고침 (`Cmd+R` / `F5`)
- 그래도 안 보이면 → 관리자(교수님 또는 시스템 담당자)에게 문의

## 4. 논문 수정·삭제

### 수정
원하는 셀을 클릭해서 그대로 수정하면 됩니다. 단, 자동 채움 컬럼(G~J)을 수정한 후에는 **K열을 `manual`** 로 바꿔주세요. 안 그러면 다음 새로고침 때 다시 덮어쓰일 수 있습니다.

### 삭제
삭제하고 싶은 행 전체를 선택 → 우클릭 → **"행 삭제"**

> ⚠️ **주의**: 삭제 후 다음날 자동 동기화 시점에 홈페이지에서도 해당 논문이 사라집니다. 임시로 숨기고 싶다면 행을 삭제하지 말고 **A열의 DOI를 잘라내서 다른 곳에 보관**해두고, 다시 게시할 때 붙여넣으세요.

## 5. 특허 추가하기

특허는 DOI가 없으므로 **`Patents` 탭**에서 수동으로 입력합니다.

### 입력 컬럼

| 셀 | 입력 내용 | 예시 |
|---|---|---|
| A열 | 특허명 | "AI 기반 제조 품질 관리 방법" |
| B열 | 발명자 (콤마 구분) | "김만수, 이재영" |
| C열 | 출원/등록번호 | "10-2024-0001234" |
| D열 | 국가 | `KR` (드롭다운) |
| E열 | 상태 | `등록` (드롭다운) |
| F열 | 연도 | 2024 |
| G열 | 제출 PI | 드롭다운 선택 |
| H열 | 분과 | 드롭다운 선택 (선택) |
| I열 | 비고 | 자유 입력 (선택) |

## 6. 자주 묻는 질문

### Q. 시트에 추가한 논문이 언제 홈페이지에 보이나요?
**A.** 매일 자정 (00:15 KST) 에 자동으로 반영됩니다. 즉시 반영이 필요하면 시스템 담당자에게 GitHub Actions의 "Sync Publications" 수동 실행을 요청하세요.

### Q. DOI 한 개를 잘못 입력하면 다른 데이터도 망가지나요?
**A.** 아니요. 각 행은 독립적으로 처리됩니다. 잘못된 DOI 한 줄은 K열에 `DOI 없음` 또는 `Error`로 표시되고, 나머지는 정상 처리됩니다.

### Q. Featured는 언제 체크하나요?
**A.** 메인 페이지나 Research 페이지 상단에 강조하고 싶은 대표 논문일 때만 체크합니다. 보통은 비워둡니다. Featured 논문은 카드 테두리가 강조되고 "FEATURED" 뱃지가 붙으며, 항상 상단에 정렬됩니다.

### Q. preprint와 publication 차이는?
**A.**
- **publication**: 정식 출간된 논문 (저널, 컨퍼런스 등)
- **preprint**: arXiv, bioRxiv 등에 올라간 사전공개 논문 (정식 출간 전)

preprint도 동일한 방식으로 DOI 입력하면 됩니다. arXiv DOI도 Crossref가 지원합니다.

### Q. 같은 논문을 여러 PI가 공저자로 있을 때 누구를 제출 PI로 적나요?
**A.** **교신저자(corresponding author)** 또는 **논문을 제출한 PI**를 적습니다. 분과 분류와 통계에서 한 명만 카운트되어야 하므로 1명만 적습니다.

### Q. 중복된 DOI를 실수로 두 번 입력하면?
**A.** 자동 동기화 시 중복은 자동으로 제거되어 한 번만 표시됩니다. 시트에서 직접 중복 행을 정리해주시면 더 깔끔합니다.

### Q. 시트 구조(컬럼)를 바꿔도 되나요?
**A.** 안 됩니다. 컬럼 순서나 헤더 이름이 바뀌면 자동 동기화가 깨집니다. 컬럼 추가가 필요하면 시스템 담당자에게 요청해주세요.

---

## 7. 문제가 생겼을 때 연락처

- **시트가 이상하게 동작**: 시스템 담당자
- **DOI 관련 문의**: 해당 논문 제출 PI
- **홈페이지 표시 문제**: 시스템 담당자
